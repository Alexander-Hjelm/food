# Soba Noodle Salad

> What are you doing onii-san? :O

## Tags

- asian, main course, cold, salad

## Ingredients

### Main + condiment suggestions

| Ingredient               | Amount     | Prep                              | Optional |
| ------------------------ | ---------- | --------------------------------- | -------- |
| Soba noodlse             | 2          | chopped                           |          |
| Cucumber                 | 1/2        | sliced thinly, salted and drained |          |
| Edamame beans            | 1 dl       |                                   |          |
| Shrimps (frozen)         | 15         | warmed up, peeled                 |          |
| Coriander                | 3-4 stalks | sliced                            |          |
| Eggs (normal or century) | 2          | hard boiled, peeled               |          |
| Tofu                     | 100 g      | Cubed and boiled                  |          |

### Soup base

| Ingredient                | Amount                       | Prep   | Optional |
| ------------------------- | ---------------------------- | ------ | -------- |
| Soy sauce                 | 3 tsp                        |        |          |
| Lemon / Chinkiang vinegar | 1/2 lemon or 3/3 tsp vinegar |        |          |
| Honey                     | 1 tsp                        |        |          |
| Sesame sauce              | 2 tsp                        |        |          |
| Sesame seeds              | 2 tsp                        |        |          |
| Garlic                    | 3 cloves                     | minced |          |
| Water                     | 3 dl                         |        |          |

## Instructions

1. Mix the soup base ingredients together and set aside
2. Cook soba noodles according to instructions, then drain with cold water
3. Arrange the soba noodles and other condiments as desired
4. Pour the soup base over the noodles and serve cold
