# Alentejo style soup

> Ay papi, this-a taste like-a soap-a!

## Tags

- soup, portuguese, main course, vegetarian

## Ingredients

| Ingredient    | Amount                    | Prep            | Optional |
| ------------- | ------------------------- | --------------- | -------- |
| Water         | 1.7 l                     |                 |          |
| Garlic Cloves | 6 large cloves            | minced          |          |
| Olive oil     | 4 tbsp + finish           |                 |          |
| Salt          | 1.5 tsp                   |                 |          |
| Coriander     | 1 bunch, fresh            | chopped         |          |
| Eggs          | 4                         |                 |          |
| Bread slices  | 1-2 per bowl              |                 | Optional |
| Peas          | 1 package preboiled, 400g | rinsed          | Optional |
| Sweet potato  | 2 large                   | cut into chunks | Optional |

## Instructions

1. Spray the sweet potato chunks with water and microwave for 4 minutes.
2. Bring the water to a boil.
3. Add garlic, olive oil, salt and sweet potato. Boil for 5 minutes.
4. Add coriander and boil for 3 minutes.
5. Poach the eggs directly in the soup to desired consistency.
6. Toast the bread and cut into pieces.
7. Assemble the soup by putting bread and beans in the soup bowl, the pour the soup into the bowl.
