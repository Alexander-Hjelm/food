## Ingredients

| Ingredient       | Amount      | Prep       | Optional |
| ---------------- | ----------- | ---------- | -------- |
| Soy beans        | 70g / 1dl   |            |          |
| Sugar            | 5-6 cubes   |            |          |
| Red dates        | 5-6 cubes   |            | Optional |
| Apple piees      | 5-6 cubes   |            | Optional |
| Water            |             |            |          |

## Instructions

1. Soak the beans for a few hours or overnight.
2. Add beans, sugar and water to the soy milk machine (0.8l for hot, 1l for cold)
3. Set the soy milk machine function to 快都将
