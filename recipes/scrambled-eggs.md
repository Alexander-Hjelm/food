# Scrambled eggs

> SCRAMLBED!!!!!!!!!

## Tags

- breakfast, vegetarian

## Ingredients

| Ingredient            | Amount                   | Prep     | Optional |
| --------------------- | ------------------------ | -------- | -------- |
| Eggs                  | 4                        |          |          |
| Salt                  |                          |          |          |
| Black pepper          |                          |          |          |
| Butter                | 1.5 tbsp                 |          |          |
| Full fat cream / milk | 25 ml cream or 1 dl milk |          |          |

## Instructions

1. Whip the eggs, cream, salt and pepper in a bowl
2. Melt the butter in a frying pan
3. Fry the mixture
